# Configure Windows Client App to trust Fiddler Root Certificate

To decrypt HTTPS traffic, you have to install and trust the Fiddler Classic root CA certificate on the client machine. Follow these steps to configure the trust.

1. [Enable HTTPS traffic decryption](slug://DecryptHTTPS).
1. Next to **Trust the Fiddler Root certificate?**, click **Yes**.
    ![Trust the Fiddler Root certificate](./images/TrustFiddlerRootCert.png)
1. After **Do you want to install this certificate?**, click **Yes**.
    ![Install this certificate](./images/InstallThisCert.png)
