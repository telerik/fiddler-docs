# Using Fiddler 

To download, install, and start Fiddler Classic:

1. Download the Fiddler product:
    - Download the latest version of [Fiddler Classic (Windows only)](https://www.telerik.com/download/fiddler).
    - Download the latest version of [Fiddler Everywhere supported on Windows, macOS, and Linux](https://www.telerik.com/download/fiddler-everywhere).
1. Install **Fiddler Classic**:
    - Select **Run** from any Security Warning dialog.
        ![Setup Security Warning](./images/setupsecuritywarning.png)
    - Agree to the License Agreement.
        ![Agree to License Agreement](./images/AgreetoLicenseAgreement.png)
    - Select the install directory for Fiddler.
        ![Select Install Directory](./images/SelectInstallDirectory.png)
    - Click **Close** when installation completes.
        ![Fiddler Classic Setup Completed](./images/FiddlerSetupCompleted.png)
1. Install **Fiddler Everywhere**:
    - Fiddler Everywhere is a modern proxy tool with cross-platform Windows, macOS, and Linux support. Apart from being a local MITM proxy, it also provides collaboration functionalities, capabilities to save and store data in the cloud, HTTP/2 and TLS 1.3 support, and many more. [Learn more about installing and using Fiddler Everywhere...](https://docs.telerik.com/fiddler-everywhere/installation-and-setup/quickstart-windows)
1. Start the desired Fiddler application and begin debugging.
